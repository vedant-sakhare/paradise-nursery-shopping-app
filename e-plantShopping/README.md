# Welcome to Paradise Nursery

Paradise Nursery is a React and Redux Toolkit shopping application for houseplants. Browse plants grouped into categories, add items to a cart, update quantities, delete items, and view live totals.

## Features
- Landing page with “Welcome to Paradise Nursery” and a Get Started button
- About Us company details
- Three categories, each with six plants
- Thumbnails, names, and prices
- Add-to-Cart buttons disabled after adding a plant
- Navigation to Home, Plants, and Cart, with a dynamic cart item count
- Quantity increment/decrement, item deletion, line totals, and cart total
- Checkout alert displaying “Coming Soon”

## Run
```bash
npm install
npm run dev
```
