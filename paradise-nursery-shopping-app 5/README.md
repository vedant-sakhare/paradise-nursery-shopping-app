# Paradise Nursery Shopping Application

A React + Redux Toolkit shopping cart for an online houseplant shop.

## Features
- Landing page with Paradise Nursery branding and a Get Started button
- About Us company information
- 18 unique plants grouped into three categories
- Add-to-cart button is disabled once a plant has been added
- Shared navigation with Home, Plants and Cart links
- Dynamic cart count
- Quantity increase/decrease and item deletion
- Per-item line totals and full cart total
- Checkout displays “Coming Soon”

## Run locally
```bash
npm install
npm run dev
```
